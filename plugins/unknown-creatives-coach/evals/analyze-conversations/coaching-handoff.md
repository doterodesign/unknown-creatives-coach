# Eval: Coaching Handoff

## Applies To
Analyze-conversations skill — the transition from the observation map into coaching

## Criteria
- After presenting the observation map, the coach asks the user where they want to start
- The transition into the follow-on coaching skill is natural and conversational — never announced mechanically
- If the user doesn't know where to start, the coach recommends based on where the strongest signal or biggest gap was found

## Pass Indicators
- The handoff question is open ("Where do you want to start?")
- Transitions carry the evidence forward ("Let's dig into how you're describing yourself — you had some interesting variations across these conversations")
- Recommendations are grounded in the analysis ("The strongest signal was around who you're talking to — I'd start there")
- The insights persist for the next skill (saved to conversation-insights.md)

## Fail Indicators
- Coach announces mechanics ("Now invoking the positioning skill")
- Coach picks the starting point unilaterally without asking
- Handoff drops the analysis — the follow-on coaching starts cold as if the observation map didn't exist
- User asked to re-describe things the analysis already established

## Weight
Medium — applies only at the transition point. If the exchange under review is mid-analysis (materials still being read or discussed), score N/A and exclude from the weighted average.
